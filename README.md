# Red Horizon

An original 3D first-person alien-invasion game prototype. Explore an occupied Earth outpost in an astronaut suit, recover three power cores, board the last ship, and reach a small civilization on Mars. This is separate from the Strapsky inventory app.

## Play locally

In this folder, run:

```powershell
python -m http.server 8000
```

Open `http://localhost:8000` in a desktop browser. Three.js and fonts currently load from public CDNs, so an internet connection is needed.

## Controls

WASD move, mouse aim, left click fire, R reload, Shift sprint, E interact, Esc pause. Click **Begin Mission** to lock the pointer.

## Current scope

This is a first playable prototype: one Earth level, basic alien combat, three mission items, a ship launch, and a Mars arrival scene. Art and gameplay will need more work before a full game release.
